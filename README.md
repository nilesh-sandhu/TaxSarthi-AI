# 🇮🇳 TaxSarthti AI

## AI-Powered GST Compliance & Business Assistant

TaxSarthti AI is an intelligent GST assistant developed using **FastAPI, Streamlit, SQLite, and Google Gemini AI**. It helps businesses search GST information, calculate GST, determine registration eligibility, check return requirements, and interact with an AI-powered GST assistant.

---

## 🚀 Features

- 🤖 AI GST Copilot
- 📦 Product GST Search
- 🔎 HSN Code Search
- 🧾 GST Registration Advisor
- 📑 GST Return Advisor
- 🧮 GST Calculator
- 👤 Business Profile Management
- 📊 Dashboard & Analytics
- 💬 Chat History
- 🔐 Authentication System

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/TaxSarthti_AI.git
```

### Backend

```bash
cd backend

pip install -r requirements.txt

uvicorn main:app --reload
```

### Frontend

```bash
cd frontend

streamlit run app.py
```
